# Remember the Note

This page already lets you edit a multiline note and Clear it. Add persistence in this browser at the same origin: reload keeps the current text, replacing it replaces the saved note, and Clear stays empty after reload, even after another Clear and reload. Keep editing and Clear working.

Storage is local to this browser context and origin, not an account, backup or sync service. Denied storage, cross-tab coordination and other browser engines are outside this example.
